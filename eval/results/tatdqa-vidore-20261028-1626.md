## Beside published results

Same 277 documents and the same 1,646 distinct questions as ViDoRe's TAT-DQA set
(vidore/tatdqa_test), scored the way its evaluator does: each question once, each document
ranked by its best page (here: its best chunk), one right document per question, nDCG@5.

Where each gain comes from: the same embedding model on our extraction and chunks beats the
paper's text pipeline by 5.8 points (56.3 vs 50.5); keyword weights and exact figures add 6.9
(63.2); the reranker adds 6.7 (69.9).

Differences that remain:
- The papers' systems are single retrievers; ours is a pipeline (hybrid search, exact terms,
  a cross-encoder reranker re-scoring 30 candidates).
- ViDoRe has one page image per document; we index every page of each document, so for 2-page
  documents we see text their systems never saw.
- Published numbers are as reported in those papers (checked against them on 28 Oct 2026),
  not re-run here.
